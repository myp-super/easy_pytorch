## 14.1 项目 1：CIFAR-10 图像分类

CIFAR-10 是 32×32 的**彩色**图片（3 通道），共 10 个类别（飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船、卡车）。比 MNIST 难很多。

### 项目要求

用全连接网络（不用 CNN），训练一个分类器，目标准确率 ≥ 50%。

```
你需要独立写：
    1. 网络类（输入 32×32×3 = 3072 维，全连接处理）
    2. 数据加载（datasets.CIFAR10）
    3. 训练循环 + 评估
    4. GPU 支持
```

### 提示

- 建议结构：3072 → 1024 → 512 → 256 → 128 → 10
- 每个 Linear 后面加 ReLU + Dropout(0.3) 很有帮助
- 训练 30+ epoch
- Adam(lr=0.001)
- 数据需要 Normalize：mean=(0.4914, 0.4822, 0.4465), std=(0.2470, 0.2435, 0.2616)

### 评分标准

| 标准 | 分数 |
|------|------|
| 网络类正确定义 | 20 |
| 数据加载正确 | 20 |
| 训练+评估循环正确 | 20 |
| 准确率 ≥ 45% | 20 |
| 准确率 ≥ 50% | 20 |

## 14.2 项目 2：房价预测（回归）

### 项目要求

使用 California Housing 数据集，训练回归模型。

```
你需要独立写：
    1. 数据加载和标准化（sklearn.datasets.fetch_california_housing + StandardScaler）
    2. 回归网络（输出 1 个值，无激活）
    3. MSELoss + 训练循环
```

## 14.4 项目 4：复现 LeNet 风格网络（挑战级）

### 项目要求

实现 `784 → 300(ReLU) → 100(ReLU) → 10` 的网络，在 MNIST 上达到 ≥ 98% 准确率。

额外要求：
1. 使用 Dropout(0.2)（在每个激活函数后）
2. 训练 30 epoch
3. 保存**最佳**模型（验证准确率最高的那个，不是最后一个）
4. 画出训练/验证 loss 曲线（用 matplotlib）
5. 展示 5 张测试图片的预测结果

### 提示

- 最佳模型保存逻辑：
  ```
  best_acc = 0
  if val_acc > best_acc:
      best_acc = val_acc
      torch.save(model.state_dict(), 'best_model.pth')
  ```
- 画 loss 曲线：`plt.plot(train_losses); plt.plot(val_losses)`
- 用 `model.eval() + no_grad()` 获取预测

### 评分标准

| 标准 | 分数 |
|------|------|
| 网络结构正确（含 Dropout） | 20 |
| 最佳模型保存 | 10 |
| loss 曲线图 | 10 |
