# PyTorch 真正初学者系统教程

## 这套教程是什么

这是一套**面向真正初学者**的 PyTorch 深度学习工程教程。

**核心目标**：关闭教程后，你能独立从零书写完整的 PyTorch 神经网络代码。

大多数教程默认你懂 `class`、`self`、`__init__`、`super()`、继承。但很多初学者根本不懂这些。

本教程把 **Python 面向对象基础**与 **PyTorch 工程代码**结合教学，不跳步骤，不偷换概念。

---

## 教程结构

```
第〇部分：Python 基础（第〇一 ~ 第〇六章）
    目标：掌握写 PyTorch 代码所需的 Python 知识
    时间：10-15 天

第一部分：基础篇（第〇章 ~ 第十四章）
    目标：能独立从零书写 PyTorch 训练代码
    时间：25-40 天

第二部分：进阶篇（第十五章 ~ 第二十一章）
    目标：掌握 CNN、RNN、Transformer 等现代架构
    时间：30-50 天
```

## 使用方法

1. **按顺序阅读**：每章建立在前一章的基础上
2. **零基础从第〇部分开始**：如果你不懂 Python 的面向对象编程，请从 `part1_python` 开始
3. **不要跳过第三章**：即使你觉得自己懂类，也请快速过一遍
4. **必须做练习**：只看不写 = 没学
5. **不看答案练习是核心**：每章末尾的"不看答案"练习是唯一检验标准
6. **如果某道"不看答案"题做不出来**：回到对应章节重新学习

---

## 教学原则

1. **一个模块只学一个核心思想**——一章不会出现十几个新概念
2. **代码量循序渐进**——从 3 行 → 5 行 → 10 行 → 20 行
3. **每个知识点 7 步教学**：概念 → 最小代码 → 逐行解释 → 可视化 → 常见错误 → 为什么这样设计 → 独立练习
4. **大量"不看答案"练习**——学完不等于学会，能独立写出来才叫学会
5. **现实世界类比**——每个抽象概念都配有直觉类比例子

---

## 代码风格

所有示例代码：
- 命名清晰（不出现 `x = foo(bar)` 这种无意义的变量名）
- 注释详细但不啰嗦
- 先给最小版本，再逐渐扩展
- 不出现 lambda、高级 Python 技巧、魔法写法
